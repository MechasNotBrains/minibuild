## minibuild vs confy
`minibuild` is a simplified version of @[heysokam/confy](https://github.com/heysokam/confy).  
Using `confy` is recommended for general purpose, as it is more actively maintained.  
confy provides more configuration and automation tools, but they are the same tool at heart.
